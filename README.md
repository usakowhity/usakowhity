AIと動物との共感・コミュニケーションをテーマに、

## 🐇 PetApp Series

PetAppは、ペットとのコミュニケーションや身体表現をテーマにした
AIペットアプリの個人開発プロジェクトです。

会話だけではなく、

- ペットとの会話
- 音声認識
- 日記
- 感情・Need
- ウサギの身体表現
- ペットの反応
- Idle Layer

などを組み合わせながら、
「ペットと一緒に過ごしている感覚」を目指しています。


## 🐰 PetApp6 — 癒しウサギの日記帳

PetApp6は、PetApp5の機能や世界観を継承しながら、
日記帳機能を追加したWebアプリです。

### Features

- 📝 日記の保存・一覧・詳細表示
- ✏️ 日記の編集・追記・削除
- 🐇 Diary → Rabbit Action
- 🎙️ Speech Recognition
- 💬 Direct Talk
- 🎬 Rabbit ActionのPNG / MP4表示
- 🖼️ 日記用サムネール
- 🖨️ 日記帳の印刷 / PDF保存
- 🌙 時間帯に応じたIdle Layer
- 🐰 Rabbit Action R01〜R23

Direct Talkでは、設定したペット名を使って、

「おはよう」
「ごはん」
「おいで」
「ハウス」
「散歩」
「おそと」
「おめでとう」
「ハッピーバースデー」

などの呼びかけに、ウサギが反応します。
